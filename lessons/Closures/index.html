JavaScript Closures

Closure là một cơ chế trong JavaScript cho phép một function tiếp tục truy cập các biến thuộc lexical scope bên ngoài nó, kể cả khi function bên ngoài đã kết thúc.

1. Khái niệm | 2. Nested functions | 3. Private variables | 4. State maintenance | 5. Tổng kết

1. Closure là gì?

  1. Outer function: function bên ngoài, nơi khai báo các biến thuộc scope mà function bên trong có thể truy cập.
  2. Inner function: function được định nghĩa bên trong outer function.
  3. Closure: inner function cùng với lexical environment mà nó ghi nhớ. Nhờ đó, function có thể tiếp tục truy cập các biến bên ngoài phạm vi trực tiếp của nó.
  4. Ứng dụng: tạo private variables và duy trì state giữa nhiều lần gọi function.

JavaScript sử dụng lexical scoping. Điều này có nghĩa là quyền truy cập biến của một function được xác định dựa trên vị trí function được định nghĩa trong mã nguồn, không phải vị trí nó được gọi.

Ví dụ 1.1: Inner function truy cập biến của outer function


    

        
        
Nhấn nút để chạy ví dụ.

    

    

    

        
    
            
  1. Ở global scope, biến message có giá trị "Goodbye".
    2. 
            
  2. Bên trong outer(), một biến khác cũng tên message được khai báo với giá trị "Hello".
    3. 
            
  3. inner() được định nghĩa bên trong outer(), vì vậy nó có thể truy cập biến message của outer().
    4. 
            
  4. Khi tìm biến message, JavaScript tìm từ scope gần nhất trước. Vì vậy kết quả là "Hello", không phải "Goodbye".
    5. 
        

    


    
Điểm cần nhớ: Inner function không chỉ truy cập được biến global. Nó còn có thể truy cập các biến được khai báo trong những scope bao quanh nó.


    

    
2. Closure có thể tồn tại sau khi outer function kết thúc

    
Điểm quan trọng của closure không chỉ là inner function truy cập biến bên ngoài. Khi outer function trả về inner function, function được trả về vẫn có thể sử dụng những biến mà nó đã tham chiếu.


    
Ví dụ 2.1: Tạo một counter bằng closure

    

    

        
        
        
        
Nhấn nút tạo counter để bắt đầu.

    

    

    

        
    
            
  1. createCounter() tạo biến cục bộ count và khởi tạo nó bằng 0.
    2. 
            
  2. Hai function increment() và getCount() được định nghĩa bên trong createCounter(), nên chúng có quyền truy cập count.
    3. 
            
  3. return { increment, getCount } trả về một object chứa hai function này.
    4. 
            
  4. Sau khi createCounter() kết thúc, ta vẫn gọi được counter.increment() và counter.getCount(). Closure giữ lại khả năng truy cập biến count.
    5. 
        

    


    
Hãy thử nhấn Increment nhiều lần sau khi counter đã được tạo. Giá trị count không bị khởi tạo lại về 0 ở mỗi lần nhấn, bởi vì tất cả các lần gọi đều làm việc với cùng một biến thuộc closure đó.


    
Vì sao đây là private variable?

    
Biến count được khai báo bên trong createCounter(). Code bên ngoài không thể truy cập trực tiếp bằng cách viết counter.count. Thay vào đó, nó phải tương tác thông qua các function được trả về.

    

    

        
        
Nhấn nút để kiểm tra.

    

    

    
Lưu ý: Đây là cách đóng gói dữ liệu thông qua closure, không phải cơ chế bảo mật tuyệt đối. Code bên ngoài vẫn có thể gọi những function mà ta chủ động cung cấp.


    

    
3. Dùng closure để duy trì state

    
Closure có thể giữ lại một trạng thái (state) và cho phép nhiều function cùng đọc hoặc cập nhật trạng thái đó. Trong video, Bro Code minh họa điều này bằng một trò chơi có điểm số.


    
Ví dụ 3.1: Quản lý điểm số của game

    

    

        
        
        
        
        
        
Nhấn nút khởi tạo game để bắt đầu.

    

    

    

        
    
            
  1. createGame() khởi tạo biến score = 0.
    2. 
            
  2. increaseScore(points) tăng điểm số.
    3. 
            
  3. decreaseScore(points) giảm điểm số.
    4. 
            
  4. getScore() trả về điểm số hiện tại.
    5. 
            
  5. Cả ba function đều truy cập và thao tác trên cùng biến score thuộc scope của createGame().
    6. 
        

    


    
Thử thực hiện lần lượt Increase +5, Increase +6 và Decrease -3. Điểm số cuối cùng là 8. Biến score không cần được đưa ra global scope để các function này có thể cùng sử dụng.


    

    
4. Closure được sử dụng ở đâu?

    
    
        
  • Private variables: giới hạn việc truy cập trực tiếp vào dữ liệu bên trong function.
    • 
        
  • State maintenance: duy trì dữ liệu giữa nhiều lần gọi function, ví dụ counter hoặc game score.
    • 
        
  • JavaScript frameworks: closure là một cơ chế thường gặp trong các thư viện và framework như React, Vue và Angular.
    •

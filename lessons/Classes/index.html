 1. JS Classes 

    
    
        
  1. Định nghĩa: class (ES6) là cú pháp "khuôn" để tạo object, gồm constructor, method, getter / setter, field và field riêng tư #. Tạo object bằng new. Bản chất bên dưới vẫn là function + prototype.
    2. 
        
  2. Khi nào dùng: cần nhiều object cùng cấu trúc và cùng hành vi (User, Product, Task); dữ liệu và hàm xử lý nó phải đi cùng nhau; cần đóng gói dữ liệu bằng field #private.
    3. 
        
  3. Khi nào KHÔNG dùng: chỉ cần một object duy nhất thì dùng object literal. Chỉ là hàm tiện ích không có trạng thái thì dùng function / module. Dữ liệu thuần từ JSON.parse không tự có method của class.
    4. 
        
  4. Tránh xung đột khi web lớn: class không được hoisted (dùng trước khai báo là lỗi). Class ở ngoài cùng trùng tên nhau gây SyntaxError như let. Quên new thì báo lỗi ngay. Field #private không file nào ghi đè được. Mỗi class nên nằm trong module riêng, đặt tên PascalCase.

 2. JS Class Inheritance 

    
    
        
  1. Định nghĩa: class Con extends Cha cho class con thừa hưởng thuộc tính và method của class cha. super(...) gọi constructor cha (bắt buộc trước khi dùng this trong constructor con); super.method() gọi method cha. Con có thể ghi đè (override) method của cha.
    2. 
        
  2. Khi nào dùng: quan hệ "là một" (Chó là một Động vật, Admin là một User); nhiều class có phần chung cần dùng lại; cần đa hình (cùng tên method, mỗi class làm một kiểu).
    3. 
        
  3. Khi nào KHÔNG dùng: khi quan hệ chỉ là "có" (Ô tô có Động cơ) thì để object chứa object (composition). Tránh cây thừa kế sâu quá 2-3 tầng, và tránh khi class cha thay đổi liên tục.
    4. 

        
  4. Khi nào KHÔNG dùng: khi quan hệ chỉ là "có" (Ô tô có Động cơ) thì để object chứa object (composition). Tránh cây thừa kế sâu quá 2-3 tầng, và tránh khi class cha thay đổi liên tục.
    5. 

        
  5. Tránh xung đột khi web lớn: quên super() thì báo lỗi ngay khi tạo object. Sửa class cha là ảnh hưởng mọi class con ở mọi file. Method ghi đè phải giữ đúng "hợp đồng" của cha (cùng tham số, cùng kiểu trả về). Thuộc tính của con trùng tên với cha sẽ ghi đè ngầm.

 3. JS Class Static 

    
    
        
  1. Định nghĩa: static method / property thuộc về chính class, không thuộc từng object. Gọi bằng TenClass.method(), object tạo ra không gọi được. Trong static method, this là class.
    2. 
        
  2. Khi nào dùng: hàm tiện ích liên quan tới class nhưng không cần dữ liệu từng object (NguoiDung.soSanhTuoi); factory method (NguoiDung.tuChuoi("An, 25")); dữ liệu chung của cả class (đếm số object, hằng số, cấu hình mặc định).
    3. 
        
  3. Khi nào KHÔNG dùng: hàm cần dữ liệu của từng object thì là method thường. Đừng biến static thành "biến toàn cục trá hình" chứa trạng thái thay đổi lung tung. Từ object phải gọi qua this.constructor.x hoặc TenClass.x.
    4. 
        
  4. Tránh xung đột khi web lớn: static là duy nhất cho cả trang: mọi file cùng sửa chung một chỗ. Chỉ cho đổi qua method (kết hợp static #private). Class con thừa kế static của cha, nếu nó là mảng / object thì dùng chung tham chiếu, sửa ở con là đổi luôn ở cha.

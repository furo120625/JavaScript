Array Sorting & Shuffling

Trong JavaScript, Array cung cấp các phương thức giúp sắp xếp và thay đổi thứ tự các phần tử. Bài học này tập trung vào hai thao tác: Sorting và Shuffle an Array.

1. Sorting | 2. Shuffle an Array

1. Sorting

Sorting là quá trình sắp xếp các phần tử trong Array theo một thứ tự nhất định, chẳng hạn như tăng dần, giảm dần hoặc theo thứ tự bảng chữ cái.

1.1. sort()

Phương thức sort() được sử dụng để sắp xếp các phần tử của Array. Mặc định, JavaScript chuyển các phần tử thành String rồi so sánh chúng theo thứ tự giá trị Unicode. 


    

        
        

    

    

    

        Lưu ý:
        
    
            
  • 
                sort() thay đổi trực tiếp Array ban đầu
                (mutates the original array).
            
    • 
            
  • 
                Mặc định, các phần tử được so sánh dưới dạng String,
                không phải Number.
            
    • 
            
  • 
                Vì vậy, không nên dùng sort() mặc định
                để sắp xếp các số theo thứ tự số học.
            
    •

2.2. Fisher-Yates Shuffle Algorithm


    

        Fisher-Yates là thuật toán phổ biến để xáo trộn các phần tử
        trong một Array. Thuật toán duyệt Array từ cuối về đầu và
        hoán đổi mỗi phần tử với một phần tử được chọn ngẫu nhiên
        trong phạm vi chưa được xử lý.
    


    

        Các bước thực hiện:
    


    
    
        
  1. Bắt đầu từ phần tử cuối cùng của Array.
    2. 
        
  2. 
            Chọn ngẫu nhiên một index từ 0 đến index hiện tại.
        
    3. 
        
  3. 
            Hoán đổi phần tử tại index hiện tại với phần tử
            tại index ngẫu nhiên.
        
    4. 
        
  4. 
            Di chuyển về phần tử đứng trước và tiếp tục quá trình.
        
    5. 
        
  5. 
            Dừng lại khi đã xử lý đến phần tử đầu tiên.
        
    6.

2.4. Shuffle an Array using a Function


    

        Có thể đóng gói thuật toán Fisher-Yates thành một Function
        để tái sử dụng.
    


    



    
    
Nhấn nút để chạy ví dụ.



    

    

        Tại sao sử dụng [...array]?
        

            Spread Operator tạo một Array mới chứa các phần tử của
            Array ban đầu. Nhờ vậy, thuật toán chỉ thay đổi bản copy,
            không làm thay đổi Array gốc.
        

        

            Đây là một Shallow Copy. Nếu Array chứa Object hoặc Array
            lồng nhau, các phần tử tham chiếu vẫn có thể trỏ đến cùng
            một Object ban đầu.

2.7. Time Complexity


    

        
            

                Algorithm
                Time Complexity
                Space Complexity
            

        
        
            

                Fisher-Yates
                O(n)
                O(1) nếu xử lý trực tiếp trên Array
            

            

                Fisher-Yates với bản copy
                O(n)
                O(n)
            

        
    


    

        Trong đó, n là số lượng phần tử của Array.
    


    


    
Summary


    

        
            

                Method / Concept
                Công dụng
            

        
        
            

                sort()
                Sắp xếp Array và thay đổi Array gốc.
            

            

                toSorted()
                Sắp xếp và trả về Array mới.
            

            

                Compare Function
                Quy định cách so sánh hai phần tử.
            

            

                a - b
                Sắp xếp Number tăng dần.
            

            

                b - a
                Sắp xếp Number giảm dần.
            

            

                localeCompare()
                So sánh String theo quy tắc locale.
            

            

                Math.random()
                Tạo số giả ngẫu nhiên từ 0 đến nhỏ hơn 1.
            

            

                Fisher-Yates
                Xáo trộn Array với các hoán vị đồng xác suất.
            

            

                Spread Operator
                Tạo bản copy nông của Array.
            

        
    


    

        Key Takeaways:
        
    
            
  • 
                Mặc định sort() sắp xếp theo String,
                không phải thứ tự số học.
            
    • 
            
  • 
                Dùng (a, b) => a - b để sắp xếp số tăng dần.
            
    • 
            
  • 
                Dùng (a, b) => b - a để sắp xếp số giảm dần.
            
    • 
            
  • 
                sort() thay đổi Array ban đầu,
                còn toSorted() không thay đổi Array gốc.
            
    • 
            
  • 
                Fisher-Yates là thuật toán phù hợp để Shuffle Array.
            
    • 
            
  • 
                Dùng Spread Operator nếu muốn Shuffle một bản copy
                thay vì Array gốc.

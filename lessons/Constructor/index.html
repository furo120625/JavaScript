1. Constructor Function là gì?

  1. Định nghĩa: constructor function là một hàm được dùng như khuôn mẫu để khởi tạo nhiều object có cùng nhóm thuộc tính.
  2. Cách viết: thường đặt tên hàm theo PascalCase, ví dụ Car, Person, Product.
  3. Vai trò của this: khi constructor được gọi bằng new, this tham chiếu đến object mới đang được tạo.
  4. Lưu ý: constructor function thông thường không có cú pháp đặc biệt. Nó vẫn là một function, nhưng được sử dụng với new.

5. Tổng kết

    

        
            

                Thành phần
                Ý nghĩa
                Ví dụ
            

        
        
            

                Constructor function
                Hàm làm khuôn mẫu để tạo object
                function Car(...) { ... }
            

            

                new
                Tạo object mới và gọi constructor với this trỏ đến object đó
                new Car(...)
            

            

                this
                Tham chiếu đến object đang được khởi tạo
                this.model = model
            

            

                Parameters
                Dữ liệu đầu vào của constructor
                make, model, year, color
            

            

                Method
                Hành vi được gắn vào object
                this.drive = function () { ... }

Phân biệt nhanh: Constructor Function và Class

    

        Video tiếp tục giới thiệu class sau phần constructor function.
        Hai cách đều có thể được dùng để tạo nhiều object, nhưng cú pháp class hiện đại
        có cấu trúc rõ ràng hơn. Phần Classes trong dự án của bạn đã là bài học
        riêng, vì vậy trang này chỉ tập trung vào constructor function truyền thống.
    

    
/* Constructor function */
function Person(name) {
    this.name = name;
}
const person1 = new Person("An");

/* Class */
class PersonClass {
    constructor(name) {
        this.name = name;
    }
}
const person2 = new PersonClass("An");

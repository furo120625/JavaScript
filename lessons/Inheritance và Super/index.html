JavaScript Inheritance and Super

Mục lục: Inheritance | Super | Tổng kết

1. Inheritance

  1. Định nghĩa: Inheritance (tính kế thừa) cho phép một class kế thừa các thuộc tính và phương thức từ một class khác. Điều này giúp tái sử dụng code và tránh viết lại những phần đã tồn tại.
  2. Class cha (Parent Class): Class cung cấp thuộc tính và phương thức để class khác kế thừa.
  3. Class con (Child Class): Class kế thừa từ class cha. Có thể sử dụng những gì được kế thừa và bổ sung thuộc tính, phương thức riêng.
  4. Cú pháp: Sử dụng từ khóa extends để thiết lập kế thừa.

- Ví dụ 1.1: Class Inheritance

Tạo class Animal làm class cha. Các class Rabbit, Fish và Hawk kế thừa từ Animal.

2. Super Keyword




    
    
        
  1. 
            Định nghĩa:
            super được sử dụng để truy cập constructor
            hoặc các method của class cha từ class con.
        
    2. 
        
  2. 
            super():
            Gọi constructor của class cha để khởi tạo những thuộc tính
            được kế thừa.
        
    3. 
        
  3. 
            super.method():
            Gọi method được định nghĩa trong class cha.
        
    4. 
        
  4. 
            Lưu ý:
            Khi class con có constructor riêng, phải gọi
            super() trước khi sử dụng this.

    Class Animal có constructor nhận vào
    name và age.
    Class con có thể sử dụng super() để gọi constructor này,
    sau đó bổ sung thuộc tính riêng.

3. Tổng kết




    

        Từ khóa
        Công dụng
        Ví dụ
    

    

        extends
        
            Cho phép class con kế thừa từ class cha.
        
        class Rabbit extends Animal
    

    

        super()
        
            Gọi constructor của class cha.
        
        super(name, age)
    

    

        super.method()
        
            Gọi method của class cha.
        
        super.move(speed)
    

    

        instanceof
        
            Kiểm tra object có thuộc class hoặc kế thừa từ class đó không.
        
        rabbit instanceof Animal

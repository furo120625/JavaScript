JavaScript Destructuring

Destructuring (phân rã) là cú pháp cho phép trích xuất các giá trị từ Array hoặc Object và gán chúng vào những biến riêng biệt một cách ngắn gọn.

1. Tổng quan về Destructuring

  1. Định nghĩa: Destructuring là cách lấy dữ liệu từ Array hoặc Object và gán trực tiếp vào các biến.
  2. Mục đích: giúp code ngắn gọn, dễ đọc và thuận tiện khi làm việc với dữ liệu có nhiều thuộc tính.
  3. Array Destructuring: lấy giá trị dựa trên vị trí của phần tử trong Array.
  4. Object Destructuring: lấy giá trị dựa trên tên thuộc tính (key) của Object.

6. Tổng kết


    

        
            

                Kiểu
                Cú pháp
                Công dụng
            

        
        
            

                Array
                const [a, b] = arr
                Lấy giá trị theo vị trí
            

            

                Object
                const { a, b } = obj
                Lấy giá trị theo tên thuộc tính
            

            

                Default Values
                const [a = 10] = arr
                Thiết lập giá trị mặc định
            

            

                Renaming
                { a: newA }
                Đổi tên biến khi phân rã Object
            

            

                Rest
                ...rest
                Thu thập các phần tử hoặc thuộc tính còn lại
            

            

                Nested
                { a: { b } }
                Phân rã dữ liệu lồng nhau
            

            

                Function
                function fn({ a })
                Phân rã trực tiếp trong tham số
            

        
    


    

        Những điều cần ghi nhớ:
        
    
            
  • 
                Array Destructuring dựa trên vị trí của phần tử.
            
    • 
            
  • 
                Object Destructuring dựa trên tên thuộc tính.
            
    • 
            
  • 
                Có thể sử dụng Default Values để tránh nhận
                undefined.
            
    • 
            
  • 
                Rest (...) phải nằm ở cuối danh sách.
            
    • 
            
  • 
                Có thể kết hợp Destructuring với Nested Array, Nested Object
                và Function.
            
    • 
            
  • 
                Destructuring không tự tạo bản sao sâu (deep copy) của dữ
                liệu lồng nhau.

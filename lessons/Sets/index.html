 1. JS Sets 

    
    
        
  1. Định nghĩa: Set là tập hợp các giá trị duy nhất (không trùng), giữ thứ tự thêm vào. Tạo bằng new Set(iterable), đếm bằng size, duyệt bằng for...of. Khi so trùng, NaN bằng NaN, còn 0 và -0 coi là một.
    2. 
        
  2. Khi nào dùng: loại trùng; kiểm tra tồn tại nhanh bằng has với tập lớn; theo dõi "đã thấy / đã chọn" (tag, id đã xử lý); các phép toán tập hợp (hợp, giao, hiệu).
    3. 
        
  3. Khi nào KHÔNG dùng: cần truy cập theo chỉ số (set[0]) hoặc sắp xếp trực tiếp thì dùng array. Cần cặp key-value thì dùng Map. Cần giữ phần tử trùng hoặc thứ tự có ý nghĩa thì dùng array. Set không loại trùng các object "giống nhau" (chỉ so tham chiếu).
    4. 
        
  4. Tránh xung đột khi web lớn: Set gán theo tham chiếu như mọi object (b = a không sao chép, dùng new Set(a)). 1 và "1" là hai phần tử khác nhau, nên dữ liệu từ ô input / API phải thống nhất kiểu. JSON.stringify(set) ra {}, hãy dùng [...set].
    5.

 2. JS Set Methods 

    
    
        
  1. Định nghĩa: add(x) thêm (trả về chính Set nên nối tiếp được), delete(x) xóa (trả true / false), has(x) kiểm tra, clear() xóa hết, size đếm, forEach, values() / keys() / entries() để duyệt. Set duyệt được bằng for...of và spread.
    2. 
        
  2. Khi nào dùng: add / has / delete để theo dõi trạng thái (đã like, đã chọn); chuyển sang mảng bằng [...set] để dùng map / filter / sort; for...of để duyệt.
    3. 
        
  3. Khi nào KHÔNG dùng: không có set.length (dùng size) và không có set[0]. Không gọi map / filter trực tiếp trên Set, hãy chuyển sang mảng. Với vài phần tử, array.includes đã đủ, đừng dùng Set cho phức tạp.
    4. 
        
  4. Tránh xung đột khi web lớn: phần tử được thêm trong lúc đang duyệt cũng sẽ được duyệt tới, nên add liên tục trong vòng lặp có thể chạy vô hạn. Đừng gán nhầm kết quả của add (là Set) vào biến khác. Set dùng chung toàn trang nên đặt trong object riêng của chức năng.

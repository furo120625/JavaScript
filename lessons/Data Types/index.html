JavaScript Data Types

Data Types (kiểu dữ liệu) xác định loại giá trị mà một biến có thể lưu trữ và những thao tác có thể thực hiện trên giá trị đó. JavaScript có 7 kiểu dữ liệu nguyên thủy (Primitive) và một nhóm kiểu dữ liệu Object.

1. Data Types | 2. Primitive Data | 3. Object Types | 4. Symbols | 5. typeof | 6. undefined | 7. NaN | 8. toString() | 9. toLocaleString() | 10. Type Coercion | 11. Type Conversion | 12. Destructuring

1. JavaScript Data Types

  1. Data Type: kiểu dữ liệu xác định loại giá trị được lưu trữ trong biến.
  2. Primitive Types: gồm 7 kiểu dữ liệu nguyên thủy: String, Number, BigInt, Boolean, Undefined, Null và Symbol.
  3. Object Type: nhóm kiểu dữ liệu phức hợp, có thể chứa nhiều giá trị và thuộc tính khác nhau.
  4. Dynamic Typing: JavaScript cho phép một biến nhận các kiểu dữ liệu khác nhau trong quá trình thực thi.

11. JavaScript Type Conversion


    

        Type Conversion là quá trình chuyển đổi một giá trị từ kiểu dữ
        liệu này sang kiểu dữ liệu khác. Khác với Type Coercion, ta có
        thể chủ động yêu cầu JavaScript thực hiện chuyển đổi.
    


    

        Phân loại:
        
    
            
  • 
                Explicit Conversion: lập trình viên chủ động
                chuyển đổi bằng các hàm như Number(),
                String() và Boolean().
            
    •

12. JavaScript Destructuring


    

        Destructuring là cú pháp cho phép trích xuất dữ liệu từ Array,
        Object hoặc các Iterable và gán chúng vào những biến riêng biệt.
    


    

        
    
            
  1. 
                Object Destructuring: lấy dữ liệu dựa trên tên
                thuộc tính (key).
            
    2. 
            
  2. 
                Array Destructuring: lấy dữ liệu dựa trên vị trí
                của phần tử (index).
            
    3. 
            
  3. 
                Default Values: thiết lập giá trị mặc định nếu
                giá trị được lấy ra là undefined.
            
    4. 
            
  4. 
                Renaming: đặt tên biến mới khi phân rã Object.
            
    5. 
            
  5. 
                Nested Destructuring: phân rã dữ liệu lồng nhau.

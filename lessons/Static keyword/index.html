JavaScript Static Keyword

Hàm trợ giúp dùng chung cho các ví dụ: 



    


    
1. Static là gì?


    

        
    
            
  1. 
                Định nghĩa:
                static là từ khóa dùng để khai báo property hoặc method thuộc về
                chính class, thay vì thuộc về các object được tạo ra từ class đó.
            
    2. 
            
  2. 
                Truy cập:
                gọi static property / method thông qua tên class:
                TenClass.property hoặc TenClass.method().
            
    3. 
            
  3. 
                Không thuộc instance:
                object được tạo bằng new không có static property / method như
                một thành viên riêng của nó.
            
    4. 
            
  4. 
                Ứng dụng:
                lưu dữ liệu dùng chung cho cả class hoặc tạo các hàm tiện ích không cần dữ liệu
                riêng của từng object.
            
    5. 
        

    


    

        Hãy phân biệt:
        this.name thường lưu dữ liệu riêng của từng object;
        static count lưu dữ liệu thuộc về class.
    


    
Ví dụ ngắn: Property thường và static property

Nhập bán kính rồi nhấn "Tính toán".

    


    

    

    

        
    
            
  1. 
                MathUtil.PI truy cập trực tiếp static property mà không cần
                tạo object bằng new MathUtil().
            
    2. 
            
  2. 
                MathUtil.getDiameter(10) gọi static method thông qua class.
            
    3. 
            
  3. 
                Trong getCircumference() và getArea(),
                this.PI tham chiếu đến static property của class trong ngữ cảnh static.

3. Ví dụ 2: User - Đếm số lượng object được tạo


    

        Video tiếp tục tạo class User. Mỗi lần khởi tạo một user,
        constructor tăng static property userCount lên 1.
        Nhờ vậy class có thể theo dõi tổng số user đã được tạo.
    


    


    

        
        
        
        
        
Chưa có user nào được tạo.

    


    

    

    

        
    
            
  1. 
                static userCount = 0 tạo bộ đếm thuộc về class User.
            
    2. 
            
  2. 
                Mỗi lần gọi new User(...), constructor chạy và
                User.userCount++ tăng bộ đếm.
            
    3. 
            
  3. 
                user1.userCount trả về undefined vì
                userCount không phải property của instance.
            
    4. 
            
  4. 
                User.getUserCount() gọi static method bằng tên class.
                Method này cũng đọc bộ đếm thông qua User.userCount.
            
    5. 
            
  5. 
                sayHello() là method thông thường vì nó cần đọc
                this.username của từng user.
            
    6. 
        

    


    


    
4. So sánh static và instance members


    

        
            

                Tiêu chí
                Static member
                Instance member
            

        
        
            

                Thuộc về
                Class
                Từng object
            

            

                Khai báo
                static count = 0
                this.name = name
            

            

                Cách truy cập
                User.count
                user.name
            

            

                Method gọi như thế nào?
                User.getCount()
                user.sayHello()
            

            

                Ví dụ trong video
                PI, userCount, getUserCount()
                username, sayHello()
            

        
    


    
5. Tổng kết


    

        
    
            
  1. static khai báo property hoặc method thuộc về class.
    2. 
            
  2. Static property / method được truy cập thông qua tên class, không phải instance.
    3. 
            
  3. Không cần tạo object bằng new để sử dụng static member.
    4. 
            
  4. Static property phù hợp với dữ liệu chung như hằng số hoặc bộ đếm.
    5. 
            
  5. Static method phù hợp với tiện ích không cần trạng thái riêng của từng object.
    6. 
            
  6. Method cần dữ liệu của một object cụ thể nên thường là instance method và sử dụng this.
    7. 
        

    


    

        Ý chính cần nhớ:
        Class sở hữu những gì được khai báo là static;
        các object được tạo từ class không sở hữu những member đó.
